# 老王内容定位——小红书版

`laowang-xiaohongshu-positioning` 面向第一次做小红书、尚未明确账号方向的创作者，通过一对一渐进访谈，帮助你从零完成个人定位、账号定位、内容定位和账号包装。

平台固定为小红书，但不预设 AI、美食、职场、育儿或其他赛道。Skill 会根据你的真实经历、能力、兴趣、资源、目标读者和长期意愿，整理多个候选账号方向供你比较选择。

## 它能帮你完成什么

1. 梳理真实的个人身份、经历、能力依据、长期兴趣和内容视角。
2. 生成 2—4 个可靠的候选账号方向，定性比较并标注推荐方向。
3. 在你选择后形成一句话和结构化账号定位。
4. 确定核心内容主题、2—3 个内容支柱和前 5 条候选选题。
5. 生成 2—3 套小红书账号包装文字方案，包括头像方向、昵称、简介和背景图文案。
6. 在最终确认后创建或更新两份 Obsidian 定位文件。

## 使用前准备

用 Codex 打开你的 Obsidian Vault。Skill 需要使用：

```text
00_个人背景/
```

如果目录不存在，Skill 会暂停并询问是否创建；只有你明确同意后才会自动创建。

## 安装方法

把下面这段话发送给 Codex：

```text
请使用 skill-installer 安装这个 GitHub Skill：
https://github.com/wzhmaggie25-rgb/laowang-xiaohongshu-positioning
```

安装完成后，可以直接开始小红书定位访谈，不需要额外启动口令。

## 使用流程

```text
个人定位访谈与确认
→ 账号方向候选比较、选择与确认
→ 内容定位访谈与确认
→ 生成并确认账号包装
→ 自动写入并复查 Obsidian
```

回答时尽量提供真实经历、时间、动作、结果和踩坑过程。想不起来时可以直接说明，不要为了完成定位而编造答案。

## 候选账号方向

Skill 会根据有效信息生成 2—4 个候选方向，不为凑数量制造牵强方案，并从以下五个维度进行文字比较：

- 个人事实与能力匹配度；
- 长期创作可持续性；
- 目标读者需求；
- 差异化；
- 执行难度。

比较不使用分数或星级，也不预测商业价值。Skill 会推荐其中一个方向并说明依据，最终由你选择。两份正式文档只保留你最终确认的方向。

## 内容定位

Skill 不固定内容赛道或内容形式。确定账号方向后，会生成：

- 一个核心内容主题；
- 2—3 个内容支柱；
- 与方向匹配的内容形式；
- 前 5 条可执行候选选题；
- 后续扩展方向和暂时不做的内容。

如果你最终选择 AI 方向，可以按需参考 AI 科普、热点、测评和教程，但不要求全部采用。

## 最终生成文件

四个阶段和最终账号包装全部确认后，Skill 会创建或更新：

```text
00_个人背景/定位总览_v0.1.md
00_个人背景/账号包装_v0.1.md
```

Skill 只写入已经确认的信息。需要匿名或不可公开的信息只记录类别和边界，不保存具体敏感内容。
