# 老王内容定位——小红书版

`laowang-xiaohongshu-positioning` 面向第一次做小红书、尚未明确账号方向的创作者，通过一对一渐进访谈，帮助用户形成一份可以开始执行并持续验证的小红书初始定位。

平台固定为小红书，不强制预设最终赛道，也不把商业化当作门槛。Skill 先从身份、目标、理念建立人物底座，再结合真实经历、能力、资源、目标读者和商业信息梳理方向；特长证据或真实付费结果任一项偏弱时，必须执行老王的“自媒体 + AI”强建议比较。

## 它能帮你完成什么

1. 从身份、目标、理念梳理人物底座、目标路径、关系视角与公开边界。
2. 判断特长证据和商业变现强度；任一项偏弱时完整比较自媒体、AI、AI×自媒体。
3. 根据用户裁决生成并比较 2—4 个优势型或探索型候选账号方向。
4. 在账号方向确认后形成轻量商业定位；没有明确目标时如实记录“暂未确定”。
5. 确定内容主题、2—3 个内容支柱和前 5 条带知识卡的候选选题。
6. 生成内容验证协议，支持用户发布后带着数据回来修订定位。
7. 从真实身份、当前行动和理念洞察提炼 2—3 套完整账号包装方案。
8. 在最终确认后创建或更新两份 Obsidian 定位文件。

## 使用前准备

用 Codex 打开你的 Obsidian Vault。Skill 需要使用：

```text
00_个人背景/
```

如果目录不存在，Skill 会暂停并询问是否创建；只有你明确同意后才会创建。

## 首次使用流程

```text
个人定位：身份 / 目标 / 理念
→ 账号定位与商业信息前置建档
→ 方向强度门禁
→ 按需比较自媒体 / AI / AI×自媒体并由用户裁决
→ 商业定位确认
→ 内容定位与验证协议
→ 账号包装选择与确认
→ 自动写入并复查 Obsidian
```

商业信息只用于说明近期目标与长期账号方向是否一致、存在张力、冲突或信息不足，不会替代长期价值和持续创作能力。Skill 不评分、不定价、不诊断产品，也不主动联网做市场调研。

## 身份、目标与理念

身份必问年龄、性别、当前工作状态、近期行动、重要事件和行为式性格；必问不等于强制回答，用户可以拒答或分别设置记录、公开边界。性格通过社交能量、表达方式、决策倾向和做事节奏理解，不强贴 MBTI 标签，也不根据年龄或性别做刻板推断。

目标区分人生目标、当前阶段目标和短期目标，并继续梳理倾向路径、排斥路径、当前行动和路径缺口。面对“想赚钱”等模糊目标，Skill 先开放追问理想状态和实现方式，不直接诱导用户选择创业、自媒体或一人公司。

理念从用户感悟最深的一句话、座右铭或长期判断出发，追问形成它的重要事件和现实体现。没有现成表达时，老王可以提出待确认的提炼候选，但不会冒充用户原话。

## 自媒体与 AI 强建议

只有同时具备重复实践、事实证明、持续投入与稳定素材来源，特长才算较强；只有已经发生的成交、付费客户或稳定收入，商业变现能力才算较强。任一项偏弱，就触发老王强建议。

触发后固定比较自媒体、AI、AI×自媒体三条路径，并说明事实匹配点、老王战略机会理由、能力缺口、执行风险和待验证项。最有依据的一条标记为“老王优先建议”；证据不足时标记为“探索型候选（待验证）”。

用户必须明确选择接受、部分接受或拒绝。完整比较只执行一次；被拒绝的路径不会进入正式候选或最终文档。强建议约束的是比较和决策过程，不强迫用户采用方向。

## 内容验证与修订

初始定位不是最终判决。建议先发布 10—20 条内容，每条提前写清要验证的是选题、表达还是内容形式，并分开观察平台流量信号和用户信任信号。

用户带着真实数据回来后，Skill 会区分证据、假设和待验证项，检查表达、选题或个人匹配问题。用户确认修订方案后，在同一份定位文件中记录 v0.2，不创建第三份正式文档。

## 账号包装

Skill 一次提供 2—3 套真正不同的完整方案，每套包括：

- 方案类型、推荐理由和一致性检查；
- 头像形式、画面建议、需要避免；
- 最终昵称和选择理由；
- 简介锚点、信息结构和 3—4 行简介，一句话一行；
- 背景图文案、视觉方向和排版建议。

候选会优先采用真实关系型、行动价值型或理念视角型等不同结构。用户可以选择一套并局部修改，最终按整套方案确认。简介以“能否看懂用户是谁或以什么视角表达、内容能带来什么具体价值、为什么值得持续关注”为验收标准，但不机械写成三段式问答。

正在构建的产品只做行动价值化表达：可以说明正在解决什么问题、服务什么人或验证什么价值，不写产品名称、产品形式、价格、销售话术或未经验证的结果。头像和背景图只输出文字方向，不生成图片。

## 最终生成文件

所有阶段确认后，Skill 创建或更新：

```text
00_个人背景/定位总览_v0.1.md
00_个人背景/账号包装_v0.1.md
```

定位总览固定包含身份、目标、理念人物底座，以及账号定位、商业定位、内容定位和版本记录；账号定位同时记录方向状态、选择依据和需要补齐的能力或证据。验证协议放在内容定位中。账号包装固定保留最终采用方案、头像、昵称、简介、背景图、一致性检查、待确认和版本记录。
